# Amidst

Landing pages for Amidst links (served with GitHub Pages).

- `/` — what Amidst is, with download links.
- `/add/?u=<username>` — a friend invite. Opens the app (`amidst://add/<username>`) when installed.

The apps live in [family-locator-ios](https://github.com/Emphasize5599/family-locator-ios) and [george](https://github.com/Emphasize5599/george).
